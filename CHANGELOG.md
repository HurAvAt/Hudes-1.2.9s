# Hudes 1.2.9s Donate edition

Adds a one-time welcome invitation and a permanent Donate button in the file filters. The wallet dialog lists Bitcoin, Ethereum, Tron, and Solana, each with its own Copy button.

# Hudes 1.2.9s

- Keep individually edited child notes, tags, and statuses across parent updates and file moves. Descendants share the top folder’s group.
- Open different installed shells in separate terminal tabs.
- Drag panel edges to resize them and pin the file details panel. Note drafts remain open during file selection.
- Customize fonts and palettes separately for light and dark mode. Existing note cards follow theme changes immediately. Resolved notes use a larger checkmark.

## Hudes 1.2.9

Hudes carries forward the file manager from Salif 5.5.2. It has a new blue infinity H, a geometric wordmark, and a header that blends into the window. The logo still locks the workspace.

Fresh workspaces start in light mode. Hudes opens earlier Salif backups and keeps a personalized workspace’s saved theme. New backups use the `.hudesdb` extension.

Windows x64 releases are available as a portable ZIP and a per-user MSI.
